# How to use
- Download the latest build.
- Put the jar in your `.minecraft/mods` folder with Meteor Client installed.
- This version is for Minecraft 1.21.11.

> This fork was updated for 1.21.11 by QrystalGG. Original Lyra credit remains with the original authors.

## Commands

- `.rename` – Renames the held item in creative mode.
- `.sptp` – Teleports using a spectator teleport packet.
- `.steal` – Steals the target's held item in creative mode.
- `.stack` – Gives you a stack of the item you're holding.
- `.summon` – Uses spawn eggs silently to spawn mobs.

<hr />

## AutoClip
Makes movement and placement easier in creative mode by helping with clipping and placement behavior.

## AutoMap
Helps you build 2D schematics by moving across blocks from the start position to the end position.

## ChatColor
Adds better chat colors and formatting for servers that support it, including ChatColor2-style support.

## CommandAura
Sends a command when players enter render distance.

Use `%target%` for the target name and `%me%` for your own name.

## ForEach
Runs a command on all players.

Use `%target%` for the target name and `%me%` for your own name.

## ItemDropper
Generates or drops items from your inventory. You can clone held items and use custom names.

## JoinMessage
Runs a command when you join a server.

Use `%me%` for your name.

## NoChatClear
Bypasses the chat clear method used by some plugins like EssentialsX.

## OnSightCommand
Runs commands on targets in sight.

Use `%target%` for the target name and `%me%` for your own name.

## PacketScaffold
Places blocks using packets under you, useful for things like spawning eggs in the air.

## RainbowArmor
Gives you rainbow leather armor with different color modes.

## Stick
Keeps you stuck to a target player.

## TpAura
Silently teleports to a target to extend the range of KillAura-style play.

## TpMine
Silently teleports you to a block and breaks it.

## Uwuifier
Uwuifies your chat messages.
